# BIMFlow · P. Avelar

Acompanhamento público do piloto de elétrica e da expansão da biblioteca BIM corporativa.

## Publicação
GitHub Pages, branch main, pasta raiz. index.html é a página principal.

## Como atualizar
1. Revise index.html com os status, números e decisões atuais.
2. Envie os arquivos alterados ao repositório (Add file > Upload files) e confirme o commit em main.
3. Aguarde a execução pages build and deployment em Actions terminar com sucesso.
4. Abra o site e confira as mudanças.

Os números e status são atualizados editorialmente; não existe sincronização automática com o Revit.
O fluxograma permite destacar etapas por status e abrir detalhes; busca, miniaturas e importação descritas pertencem ao plugin Revit.

## Arquivos
- index.html: guia, imagens incorporadas e fluxograma interativo.
- BIMFlow-Estrutura-GitHub.svg e .png: diagramas para download.
- BIMFlow-Fluxograma.svg: versão estática do roadmap para exportação.
- catalogo-eletrica-exemplo.json: exemplo do contrato, não catálogo completo.
- .nojekyll: publicação estática.

O site e o repositório são públicos. A DLL e o RVT não fazem parte desta publicação.
Publicar o acompanhamento não implementa a distribuição online de conteúdo pelo plugin.
